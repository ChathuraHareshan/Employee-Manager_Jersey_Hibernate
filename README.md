# Jersey Employee Management System

A simple Employee Management System developed using Java Jersey REST API.

## Features

- Add New Employees
- View Employee Details
- Update Employee Information
- Delete Employees
- RESTful API Operations

## Technologies Used

- Java
- Jersey (JAX-RS)
- REST API
- MySQL

## Project Description

This project is a simple employee management system that allows users to manage employee records through REST API endpoints. It supports basic CRUD operations such as creating, reading, updating, and deleting employee details.

## CRUD Operations

| Method | Operation | Description |
|---|---|---|
| POST | Add | Add a new employee |
| GET | View | Retrieve employee details |
| PUT | Update | Edit employee information |
| DELETE | Delete | Remove an employee |
